# Kiểm tra bản bàn giao

Đã đối chiếu 14 model với hình Database Schema của RDS; kiểm tra cấu trúc XML của pom.xml/web.xml, 24 UC có trang khung, mapping servlet không trùng, đích JSP tồn tại và include header/footer hợp lệ.

Môi trường tạo ZIP không có javac, Maven hoặc Tomcat; chưa biên dịch Java, chưa chạy JSP trên server, chưa kết nối SQL Server của bạn. Không coi kiểm tra tĩnh là xác nhận chạy thành công. Làm các bước README trên máy bạn để xác nhận build và kết nối.
